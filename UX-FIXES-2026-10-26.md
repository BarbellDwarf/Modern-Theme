## Still open (not in this pass)

1. **Contrast system-wide** (light mode): post body/muted text is very faint (screenshot v20: QA strings nearly unreadable); white-on-orange links/buttons ~3:1. This is the largest remaining "doesn't feel good" factor for a 50+ audience. Needs a token pass (`--text-muted`, link and button colours), not per-component patches.
2. **Mobile header crowding**: site name truncates to "TEST - Grace…"; five actions + badge in one row; icon styles mixed. Needs a decision: fewer actions (move mail/notifications into one overflow) or a second row.
3. Composer placeholder truncates on mobile ("Share something with th…").
4. Comment counter format on posts ("Comment(4)") — copy pass covered "Comments (N)" where the theme controls it; the per-post pill still uses core's string in some places.
5. Profile depth: initials and empty-row hiding are in; phone/email/household fields still disabled at the platform level (privacy decision for the owner).
6. P2 items from the review: duplicate Join/Follow affordances, three date formats, "Usermap" naming (owner chose to keep), false "unsaved changes" prompt, notification/calendar empty-state polish.
7. **Production deployment**: none of these theme changes are on production yet (it still runs the 1.18-era theme build). The branch is dual-safe, but production needs a deliberate rollout decision.
