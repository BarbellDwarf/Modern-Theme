# HumHub UI — Full Review Report (2026-10-26)
**Instance:** gbc-social1 test (HumHub 1.19.0 + theme `humhub-1.19-compat`)
**Method:** dogfood exploratory QA (click-through, console capture, interaction states) + impeccable design critique (hierarchy, contrast, motion, polish)
**Coverage:** 11 surfaces × light/dark × desktop/mobile(390×844) + 6 interaction states + asset/console checks
**Evidence:** `/home/river/ui-review-evidence/` (L*.png light, K*.png dark, I*.png interactions)

---

## Verdict
**"Looks good"? Not yet — it's functional and consistent, but not polished.** The bones are right (card system, spacing scale, 150–250ms motion, coherent dark palette) but contrast, accent overload and a handful of dark-mode/empty-state gaps keep it feeling washed out and unfinished. **"Feels good"? Partially:** clicks respond, transitions are consistent, likes/reactions work; but dead affordances (blank mail inbox until fixed today, invisible composer submit until focus) make it feel unreliable.

## Open issues by priority

### P1 — functional / blocking quality
1. **Mail inbox stops rendering when the theme's mail JS is active** (F2) — port in progress; until then mail runs with the script disabled (no mobile mail sheets).
2. **Dark mode: calendar month title invisible** — "October 2026" is dark gray on dark navy (~1.5:1). Grid itself themes correctly.
3. **Dark mode: light leftovers** — space/profile cover banners stay pale gradients with white title text (~2.5:1), avatar placeholders glare; dashboard cards blend into the page (no surface separation).
4. **Contrast system-wide (AA failures)** — white-on-orange links/buttons (~3:1), orange links on white (~3.5:1), gray meta text (~2.8:1), footer links. Both modes.

### P2 — interaction & consistency
5. **Reaction picker**: works, but labels ~9–10px, cells ~40px, no anchor arrow, overlaps media.
6. **Comment composer**: no visible submit button until focus; placeholder low contrast; 4 comments hidden behind "Show previous 2".
7. **Search popover**: no placeholder, no visible submit action, occludes content, pale input border.
8. **Notifications**: filter tabs wrap; master "All" checkbox styled differently from children; weak empty state; unexplained gear.
9. **Mail (now rendering)**: inbox panel collapses to content instead of filling the column; no page title/breadcrumb; empty state is a bare sentence with no CTA; `+` compose is an unlabeled icon; right reading pane is blank white/dark with no empty-state message when nothing is selected.
10. **Space header**: white title on light banner; avatar overlap into stats; Join+Follow+gear redundancy; "1 Posts" pluralization; clipped active-nav indicator (mobile).
11. **Login**: always-on orange input border (reads as error/focus); duplicate label/placeholder; top-weighted vertical layout; edge-to-edge divider; two-step flow unannounced.
12. **404 page**: orange-on-orange CTA (~2:1), chevron glyph collides with label, "Powered by HumHub" twice, top-heavy.
13. **Admin pages on mobile**: full desktop layout (255px sidebar, tables overflow, tabs wrap) — no responsive treatment.
14. **Accent overload**: orange does 5 jobs (brand, links, CTA, icons, background); red brand text adds a second competing accent.

### P3 — polish
15. Video embed: fade-to-white bottom edge, square corners vs rounded UI, unlabeled "45", title truncation collides with logo mark, ~16px controls.
16. "Comment(4)" → "Comments (4)"; lone smiley needs a tooltip; like/comment/reaction actions scattered across the footer baseline.
17. Three date formats on one screen; hyphenated "impor-tant"; mixed avatar placeholder styles (silhouette vs initials).
18. Dashboard has no visible create-post affordance (user must go to a space).
19. Reaction picker + like both present with unclear division of purpose.

## What's genuinely good (keep it)
- Card radius/shadow system is consistent; 8px spacing scale holds across pages.
- Motion: 150ms (inputs) / 250ms (buttons, cards) — consistent, not sluggish; likes animate.
- Dark palette tokens are coherent where applied (body #0f172a, cards slate) — the gaps are specific leftovers, not a broken theme.
- Mobile bottom-nav pattern (Home/Spaces/Directory/Notifications/More) is the right call and touch targets were raised to 44px in the stream.
- Login page's single-card composition is clean; only state styling and centering need work.
- Reaction picker's Facebook-style set is appropriate for the audience; needs sizing/anchor fixes only.
